# Security Policy

Please do not include secrets, private launch plans, unpublished customer data, or private social account details in public issues.

For security-sensitive reports, contact the maintainer privately before publishing details. Include the affected version or commit, the command you ran, and the smallest safe reproduction you can share.

`postmaker` is local-first and does not post to external platforms. Report any behavior that unexpectedly sends network requests, mutates accounts, or treats unsourced claims as publish-ready.
