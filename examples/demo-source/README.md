# DemoLaunch

DemoLaunch is a fixture product used to show how postmaker keeps social drafts
tied to local evidence.

- Generates launch copy from README and package metadata.
- Marks claims with review status before publishing.
- Leaves posting to a separate human-approved workflow.

## Demo Flow

Run postmaker against this fixture, inspect `post-pack.json`, then run the claim
checker before adapting any draft for a real account.
